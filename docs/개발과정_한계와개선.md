# SunSight 모델 ③ — 한계를 만나고 고쳐 온 과정

프로젝트 진행 과정을 "한계 → 의문 → 고친 점" 순서로 정리한 문서.
큰 흐름만 정리. 세부 수치 · 식은 노션 데이터 명세서 · 분석계획서 모델 ③ 칸 참고.
순응 점수 A 계산은 아직 초안 (업데이트 중, 담당자 검토 전).

마지막 갱신: 2026-11-04 오후

| 13. 사람 근거 | 휘도비는 숫자일 뿐, 사람 눈 기준이 없음 | 공개 동공 데이터로 "동공이 몇 mm 커져야 하나"로 번역 |

## 1. 주제 정하기

**한계**
- 처음 후보 대부분이 흔하거나(따릉이 · 영화 · KBO) 데이터가 부족했음

**고친 점**
- 기준 세 가지로 다시 고름: 비즈니스 의미 · 데이터 수집 쉬움 · 학습할 만큼의 양
- 태양 눈부심과 터널 진입 · 탈출이 사고에 주는 영향으로 확정

---

## 2. 데이터 찾기

**의문점**
- 인수인계 받은 데이터 번호가 맞는 자료인가?

**한계**
- 2개는 엉뚱한 자료 (자전거 사고 다발지역, 대전 유성구 사고 현황)
- 시내 일반도로는 분 단위 개별 사고 공개 데이터가 없음

**고친 점**
- 직접 열어 확인: 한국도로공사 고속도로 사고 4,458건 (일자 · 분 단위 시각 · 좌표 · 날씨)
- 터널 3,840개, 기상청 시간별 기상 추가
- 학습은 전국 고속도로, 적용은 대구 출퇴근길로 나눔

## 3. 분석 방향

**한계**
- 강사 피드백: 시뮬레이터만으로는 부족, 예측 모델이 핵심

**개선한 점**
- 목표를 "출퇴근길 지점 · 시각별 사고확률"로 정함
- (11/3 바로잡음) 목적은 "일조량으로 순응 효과가 생기는 지점의 사고 발생 확률". 위치 · 시각 자체를 예측하는 모델이 아님 → 11절
- 영상은 보조로 내리고 공개 사고 데이터로 학습하는 구조로 바꿈

## 4. 팀과 역할 나누기

**의문점**
- 팀 설계(1 km 구간 사고 수, 눈부심 분류)와 우리 기획이 겹치지 않나?

**고친 점**
- 눈부심은 모델 ① · ②, 터널 순응은 모델 ③으로 나눔
- 한 변수가 두 모델에 같이 들어가지 않게 정리 (해 방향 · 역광은 모델 ② 몫)

## 5. 순응 점수 A 만들기

**의문점**
- 터널 안 밝기 기준값 280 · 45는 어디서 나왔나?

**한계**
- 처음엔 KS 규격 값을 논문에서 재인용 → 원문 확인 불가
- 실제 터널 조명 측정값은 공개된 게 없음

**고친 점**
- 국토부 「도로안전시설 설치 및 관리지침 — 조명시설 편」 원문으로 근거 교체
- 바깥이 밝을수록 터널 입구 조명을 올리는 조광 4단계 반영
- 출구 45는 국제 기준(CIE)에서 온 값이라는 점을 명시

**남은 한계**
- 모든 터널이 지침대로 조명을 켰다고 가정
- 지침 원문과 다시 대조하니 구간 길이 3곳이 다름 → 검토 중

---

## 6. 비교 방법 바꾸기

**의문점**
- 사고 난 곳과 아무 곳이나 비교하면 햇빛 효과만 볼 수 있나?

**한계**
- 무작위 대조군은 장소 · 교통량 차이가 섞여 햇빛 효과가 가려짐

**고친 점**
- 같은 자리 비교: 사고 1건마다 같은 자리 · 같은 달 · 요일 · 시각의 다른 주 3~4개와 비교
- 장소 차이가 지워지고 그날 밝기 차이만 남음
- 조건부 로지스틱으로 "A 0.1 오르면 위험 몇 배"를 구함

**개선한 점**
- 출퇴근 확률 = 기본 사고율 × 햇빛 배수로 구조를 단순하게 정리
- 기본 사고율을 터널마다 따로 재면 대부분 0이 나오는 문제를 확인 (사고 지점 200곳 중 157곳이 3년간 1건)

## 7. 도로 위에 사고 올리기

**한계**
- 사고 기록의 "방향"이 도시 이름이라 어느 차로인지 불분명
- 다수결 방식으로 정했더니 1,903건이 반대 차로에 붙음

**고친 점**
- 노선별 방향 규칙표를 만들어 57건까지 줄임
- 4,458건 중 4,443건을 도로에 올림 (빠진 15건도 하나씩 확인)

## 8. 일사량 버그

**의문점**
- 한낮 사고인데 왜 A가 0인 사고가 많지?

**한계**
- 일사를 재지 않는 관측소 26곳의 빈칸이 0으로 채워짐
- 사고의 약 32%가 한낮에도 A = 0
- 점검을 "값이 붙었나"로만 해서 0도 정상으로 통과

**고친 점**
- 일사를 재는 관측소 49곳 중 가장 가까운 곳 값을 씀
- 점검 항목에 "한낮인데 일사 0인 비율" 추가

**개선한 점**
- 같은 시각 비교가 가능한 묶음이 늘어 결과가 더 믿을 만해짐

## 9. 결과 읽기

**결과 (초안)**
- 진입 낮 사고 139묶음: A 0.1당 1.25배 (95% 범위 0.93~1.68)
- 사고 날이 평소보다 밝았던 묶음 82 vs 어두웠던 묶음 51
- 진출은 차이 없음
- (11/3 저녁 로컬 PC 재실행: 136묶음, ASOS 1.22배 → 10절)

**의문점**
- 1.25배인데 왜 "확정"이라고 못 하나?

**정리한 답**
- 범위가 1(효과 없음)을 포함 → 아직 확정 못 함
- 범위 대부분이 1보다 크고 방향 세기도 같은 쪽 → "밝을수록 위험한 쪽으로 기우는 경향"
- 비를 같이 넣어야 A 효과가 가려지지 않음 (비 빼면 1.20, 넣으면 1.25)

**한계**
- 낮 진입 사고가 139건뿐이라 범위가 넓음 (약 250묶음이면 범위가 1을 넘을 수 있음)

## 10. 위성 일사량으로 다시 재기

**의문점**
- 관측소가 사고 지점에서 멀어(중앙값 16.8 km) 결과가 흔들린 것 아닌가?

**한계**
- 첫 요청은 API가 한 번에 24개까지만 줘서 전부 실패 → 사고 앞뒤 1시간만 요청하게 고침

**확인한 것**
- 천리안 위성 vs ASOS 일사량: 상관 0.896 (887일), 중앙값 비 1.0, 0.5 MJ 넘게 차이 나는 날 12% → 두 측정이 거의 같음
- 천리안으로 바꿔도 진입 1.16배 (95% 0.87~1.53), ASOS는 1.22배 → 결론 같음
- 진출은 어느 쪽으로도 신호 없음

**정리**
- 범위가 넓은 이유는 측정이 아니라 사고 수 (진입 낮 136건)
- "관측소가 멀어서 못 믿는다"는 반론에 답할 근거가 생김
- 솔직한 결론: 효과 크기 자체가 작다. 위성으로 측정을 바꿔서 해결되는 문제가 아니었음
- 주 분석은 ASOS 유지, 천리안은 민감도 분석으로 (11/4 팀 슬랙 · 노션 · 깃허브 공유)

## 11. 비판적 재점검 — A가 정말 "순응"을 재나

**의문점**
- A는 일사량 → 바깥 밝기 → 터널 안 기준값과의 비율. 터널 안 값은 지침 상수라 날마다 안 바뀜
- 그러면 A에서 날마다 실제로 바뀌는 값은 사실상 일사량 하나 아닌가?

**한계**
- 일사량이 높은 날은 순응 부담도 크지만, 교통량 · 나들이 차량 · 눈부심도 같이 달라짐
- 지금 결과만으로는 "순응 때문"인지 "맑은 날이라서"인지 구분 못 함

**고친 점**
- 목적 표현을 바로잡음: "일조량으로 순응 효과가 생기는 지점(터널 입 · 출구)의 사고 발생 확률". 위치 · 시각 예측 모델이 아님
- A 효과를 "순응 효과"로 단정하지 않고 "맑은 날 터널 입구 위험"으로 보고

**개선안 (검토 중)**
- 터널 없는 구간과 비교: 같은 맑은 날, 터널 없는 고속도로 구간에서도 위험이 같이 오르면 순응이 아니라 날씨 · 교통 효과
- 역광 입구 비교: 해를 정면으로 보고 들어가는 입구 vs 등지고 들어가는 입구 → 눈부심과 순응 나누기

---

## 12. 방향 바꾸기 — 사진 한 장으로 순응도 추정

**한계**
- 사고 확률 예측은 효과가 작고(1.16~1.22배, 범위가 1 포함) 공격받을 곳이 많음
- 사고 유무를 규칙 vs ML로 맞히는 안도 결국 사고 예측이라 "순응"을 배우지 않음

**바꾼 방향**
- 운전 중 보이는 터널 입구 사진 한 장 → 지금 이 터널이 눈에 주는 순응 부담(순응도) 추정
- 입력: 사진 숫자 (하늘 밝기, 입구 밝기, 입구/주변 밝기비, 그림자 대비 등)
- 정답: 그 사진을 찍은 시각 · 장소의 실측 일사량으로 계산한 휘도비 → 순응도
- 보여줄 것: 단순 규칙("사진이 밝으면 위험" 등)보다 ML이 더 잘 맞힘, 처음 보는 터널로 시험
- 사고 데이터는 보조 확인 ("순응도 높은 시각에 사고도 많았나", 경향 수준)

**의문점 — "사진으로 사진을 맞히는 것 아니냐"**
- 정답을 사진에서 계산하면(입구 밝기 ÷ 주변 밝기) 모델은 우리가 쓴 나눗셈만 배움 → ML이 필요 없음
- 그래서 정답은 사진 밖(그 시각 · 장소의 일사량)에서 가져옴. 사진에는 일사량 숫자가 없으니 ML이 필요한 이유가 생김
- 시각 · 좌표는 정답 계산에만, 모델 입력에는 안 넣음
- 학습은 사진, 사용은 주행 영상이어도 문제없음. 핵심은 정답이 어디서 오느냐

**고친 점 (11/4 오후)**
- 비교 대상을 규칙 하나가 아니라 규칙 여러 개(손 규칙 · 경계값 학습 · 한 숫자 직선 · 물리 공식 · 계절 · 구름 표)로 → 모델 ② 방식
- 규칙과 ML 모두 같은 사진 숫자를 받음. 주 지표는 미리 고정: 처음 보는 카메라에서 위험도 3등급 macro-F1
- 발견: 터널 입구 조명이 바깥 밝기에 맞춰 세지기 때문에(조광) 입구 순응도가 0.43~0.63으로 거의 일정
- 결정 (11/4): 주 방향 = 사진 → 바깥 밝기 → 공식으로 순응도 · 동공 · 위험도 (순응도 직접 맞히기는 비교용). 위험도 = 휘도비 등급, 동공은 설명용. 등급 경계값은 아직 초안

**버린 안 (발표 때 보여줄 것)**
- 사고 확률 예측 → 보조로 / 사고 유무 분류 → 버림 / 입구 가시도 사람 라벨 → 최후 수단 / VDS 감속량 → 검지기 위치 미확인으로 보류

## 13. 사람 근거 — 동공

**의문점**
- 휘도비는 숫자일 뿐. 사람 눈에 얼마나 부담인지는?
- 동공이랑 망막도 같이 해야 하나?

**정리**
- 공개 데이터 SpectroSense (83명, 빛 · 동공, CC BY 4.0)로 "빛 → 동공 지름" 모델 → 휘도비를 "동공이 몇 mm 커져야 하나"로 번역
- 망막 순응은 공개 데이터로 잴 방법이 없음 → 논문 값으로 한계에 적음
- 발표 문장: "동공으로 본 순응 부담. 실제 순응은 망막까지 포함해 더 크고 길다"

## 13-2. 조광 발견과 정답 바꾸기 (11/4)

- **한계**: 터널 입구 조명은 바깥 밝기에 맞춰 조광한다. 그래서 바깥이 4배 밝아져도 입구 A는 0.43~0.63으로 거의 그대로다 → 정답이 안 변하면 ML이 배울 게 없다
- **의문**: 그러면 무엇을 맞혀야 하나? 동공만으로 등급을 매기면 "흐린 날이 더 위험"이 되어 사고 경향과 반대
- **고친 점**: ML은 실제로 변하는 **바깥 밝기**를 맞히고, A·동공·위험도는 공식으로 계산. 위험도 등급은 휘도비 A로, 동공은 "눈이 몇 mm 움직여야 하나" 설명용 (11/4 결정)
- **개선**: 규칙 7종 vs ML을 모델②와 같은 틀로 비교(같은 숫자, 규칙도 경계값 튜닝, 주 지표 고정, 처음 보는 카메라). 71786이 전부 맑은 날이라는 약점은 천리안 확인 + 흐린 날 보충으로

## 13-3. 위험도 등급 경계 (11/4, 초안)

- **의문**: 휘도비 몇 배부터 "중", 몇 배부터 "상"인가?
- **시도**: 문헌 경계(10배 · 15배, Schreuder 1991)와 사고 데이터로 찾은 경계를 비교
- **결과**: 사고 데이터로는 "중" 1.61배 (p 0.07), "상" 1.09배 (p 0.79) → 경계가 흔들려서 근거로 쓰기 어려움
- **고친 점**: 일단 문헌 경계 유지. 최종 경계는 사진에서 휘도비를 뽑는 방식이 정해진 뒤 다시 결정 (11/4 결정)
- **한계 한 줄**: 동공은 밝기 변화의 일부만 조절하고 나머지는 망막이 감당한다 (입구 기준 동공 약 1.5배, 나머지 약 8배는 망막 몫) → 동공 수치는 "최소한의 부담"으로 설명

## 13-4. 첫 실험 — 규칙 vs ML (11/4, 임시 정답)

- **시도**: Mapillary 105장(78장면)으로 사진 → 바깥 밝기. 규칙 5종 vs ML 3종, 장면 단위로 나눠 채점
- **개선한 점**: 사진만 쓰는 줄끼리는 ML이 규칙보다 확실히 나음 (오차 0.21 vs 0.37~0.42)
- **한계**: 사진만으로는 해 높이 · 구름 규칙(오차 0.08~0.11)을 못 이김. 바깥 밝기는 해 높이와 구름이 대부분 정함
- **고칠 점**: 사진 + 해 높이 · 구름 ML이 가장 좋음 (오차 0.077, 위험도 F1 0.75) → 주 모델 후보 (결정 대기)
- **의문**: 정답과 구름 규칙이 같은 ASOS 관측소 값이라 규칙 쪽이 유리 → 천리안 정답으로 다시 잼
- 이행부는 사고 범위에 넣지 않기로 함 (11/4 결정)
