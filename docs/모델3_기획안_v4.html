1터널 순응이란

밝은 바깥에서 어두운 터널로 들어가면 몇 초 동안 앞이 잘 안 보인다. 이게 순응 문제다.
  • 암순응: 밝은 곳 → 어두운 곳 (터널 입구). 오래 걸림
  • 명순응: 어두운 곳 → 밝은 곳 (터널 출구). 빨리 끝나지만 "하얀 구멍" 눈부심
  • 눈이 힘든 정도를 정하는 것 = 바깥과 안의 밝기 비율(휘도비)
  • 100 km/h면 1초에 28 m. 순응 3초 = 약 83 m를 잘 못 보고 달림 (홍기혁, 자연터널지하공간 20(2))

핵심 질문: "태양 일사량 때문에 순응 부담이 커지는 지점에서 위험이 얼마나 커지나". 어느 자리 · 어느 시각에 사고가 나는지를 맞히는 모델이 아님.

5조광: 입구 A가 거의 일정한 이유

입구 조명은 바깥이 밝으면 세게, 어두우면 약하게 켠다. 분자와 분모가 같이 커져서 비율이 거의 그대로다.
  • 지침 원문 (159쪽 6.6.1 · 표 6.7): "입구부 조명은 터널입구 부근의 야외휘도에 따라서 조절하는 것이 바람직". 바깥이 100 / 75 / 50 / 25%로 줄면 안도 같은 비율 이상
  • 설계상 비율 ≈ 4,000 ÷ 280 = 약 14배 유지 → 입구 A 0.5대는 계산 실수가 아니라 지침대로 한 결과
  • 입구가 위험해지는 때 = 조광이 못 따라갈 때: 바깥이 4,000을 넘어 조명이 이미 최대일 때
  • 출구는 조광 없음 → 바깥 밝기를 그대로 따라감
그래서 ML은 실제로 날씨 따라 크게 변하는 바깥 밝기(500 → 5,000)를 맞히고, 조광 · 입구/출구는 뒤 공식에서 끼운다. 터널마다 조광이 달라도 모델 하나로 됨.

한계: "바람직하다"라 강제 아님. 실제 터널이 시간표로만 조절하면 입구 부담은 더 큼 → 한계 한 줄 + 조광 없는 최대 부담(280 고정)도 같이 계산.

7동공과 망막: 왜 등급은 휘도비인가

동공은 빛의 일부만 조절한다. 큰 몫은 망막이 맡는다. 동공 변화량만 보면 순서가 뒤집힌다.

동공으로 등급을 매기면 생기는 일

입구 날씨휘도비동공 변화량 (40세)
조금 흐림 (0.5)12배0.72 mm (가장 큼)
보통 (1.0)12배0.59 mm
맑음 (2.0)12배0.48 mm (가장 작음)

→ "맑은 날이 가장 안전"으로 나옴. 사고 경향(맑은 날 진입 1.16~1.25배), 지침과 반대. 동공은 두 밝기의 절대값을 따르고, 밝은 곳에선 이미 최소(약 2 mm)라 더 못 줄어듦.

망막 몫 = 휘도비 ÷ 동공 면적비 (발표 설명용, 모델 계산 단계 아님)

휘도비동공이 맡는 몫망막이 맡는 몫
입구, 흐림7배1.5배4.7배

  • 망막 몫 순서 = 휘도비 순서 → 등급은 휘도비로 충분
  • 적응 시간을 늘리는 것도 망막: 바깥이 밝았을수록 회복이 느림 (암순응 곡선)
  • 동공 면적: SpectroSense엔 지름(diameter_3d)만 있음 → 면적 = 3.14 × 지름² ÷ 4
  • 동공 값은 지금 Watson & Yellott 2012 공식(40세). 팀원 동공 모델(ML-1) 나오면 실제 데이터 값으로 교체

  2. 그런데 사진만으로는 시각 · 구름 규칙을 못 이김 (오차 0.21 vs 0.08~0.11). 해 높이와 구름이 바깥 밝기를 대부분 정함
  3. 사진 + 해 높이 · 구름 LightGBM이 위험도 F1 최고 (0.75 vs 규칙4 · 5 0.68~0.69). 사진이 날씨 정보에 조금 더 보탬

  • 정답(ASOS 일사)과 규칙5의 구름이 같은 관측소 값 → 규칙5가 유리하게 나옴. 천리안 정답이면 달라질 수 있음

  • 입구/출구 분류 전이라 위험도 F1은 참고만
제안 (결정 필요): 주 모델 = 사진 + 해 높이 · 구름. 운전 중에도 휴대폰 시각 · GPS와 날씨 API가 있으니 현실적. 모델②의 G(해 위치 + 날씨 + 화면)와도 같은 구조. "사진만" 모델은 사진의 기여를 보여주는 비교 줄로.
